Prédiction du prix immobilier

Modèle Random Forest prédisant le prix d’un bien immobilier à partir de ses caractéristiques. Déployé avec Flask pour test interactif.

Scikit-learn · Random Forest · RMSE 166k · R² 64%

  • Variables principales : superficie, nombre de chambres, salles de bain, étage, vue, âge, etc.
  • Les variables catégorielles de localisation (ville, rue) étaient inutilisables en prod, seule la variable Zip-code est conservée
  • Exemple d’utilisation : l’utilisateur entre la superficie, chambres, salles de bain, Zip-code, date,la vue sur l'eau(0 NON 1 oui),la qualité_vue,l etat general vont de 1 a 5 le codezip généralement entre 5 ou 6 chiffres(voir sur internet les codes en fonction des villes souhaitées)
  • Note : modèle donne un R² de 0.64 – raisonnable mais pas parfait
  • déployer via replit pour un test rapide
